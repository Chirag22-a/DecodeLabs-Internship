# DecodeLabs AI Internship Projects

This repository contains the AI internship project work.

## Project 1: Rule-Based AI Chatbot

The chatbot and its instructions are in [`project-1-rule-based-chatbot`](project-1-rule-based-chatbot/README.md).

To run it from the repository root:

```powershell
cd project-1-rule-based-chatbot
py chatbot.py
```

## Project 2: Iris Flower Classification

The KNN classification project is in [`project-2-iris-classification`](project-2-iris-classification/README.md).
It loads and explores the Iris dataset, compares K values using training-only
cross-validation, then reports accuracy, F1, and a confusion matrix on held-out
test data.

## Project 3: Tech Stack Recommender

The recommendation project is in [`project-3-tech-stack-recommender`](project-3-tech-stack-recommender/README.md).
It ranks career paths and example tools from a skills catalog using TF-IDF and
cosine similarity.

## Project 4: Image and Text Recognition

The OCR project is in [`project-4-image-text-recognition`](project-4-image-text-recognition/README.md).
It preprocesses an image with OpenCV, extracts printed text with Tesseract, and
reports confidence with an annotated visual result.
